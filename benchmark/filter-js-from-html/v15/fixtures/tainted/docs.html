Overview

The SDK renders embedded widgets for approved product surfaces.

Use semantic HTML in guides so screen readers can navigate examples correctly.

Install

npm install @northwind/widget-sdk

Pin a tested version in production release branches.

Configuration

KeyRequiredDescription
tenantIdYesTenant identifier supplied by operations.
themeNoOptional theme preset such as light or slate.
regionYesDeployment region used for asset routing.
timeout = 30 + retryBudget

Need a sample app? Open the quickstart helper.

FAQ

Does the widget require a framework?

No. It can be mounted from plain HTML.

Where do I find changelogs?

Use the release notes page linked from the engineering portal.
