# Audio Synthesis + STFT + Peak Extraction Pipeline

## Overview

This skill addresses the family of tasks that combine three stages:
1. **Audio synthesis**: Generate deterministic WAV files from parametric signals
2. **STFT computation**: Compute Short-Time Fourier Transform using scipy
3. **Peak extraction**: Extract top-k spectral peaks per frame using awk

The pipeline is orchestrated by a bash script that supports a `PEAKS_ONLY` mode for
re-running only the peak extraction stage.

## Core Architecture

### File Structure
```
/app/
├── audioproc.py              # Python: synthesis + STFT computation
├── run_audio_pipeline.sh     # Bash: pipeline orchestration + awk peak extraction
└── data/
    ├── clip.wav              # Synthesized audio (PCM int16)
    ├── mag.csv               # STFT magnitude (frame,bin,val)
    └── peaks.csv             # Top-k peaks per frame (frame,f1_bin,...,fk_bin)
```

### Stage Separation
- **Python (audioproc.py)**: Generates WAV and computes STFT magnitude CSV
- **Awk (via bash script)**: Extracts peaks from magnitude CSV
- **Bash script**: Orchestrates pipeline, supports PEAKS_ONLY mode

**Critical invariant**: `peaks.csv` must be generated by awk, not Python. The Python
script only produces `clip.wav` and `mag.csv`.

## Stage 1: Audio Synthesis

### Signal Generation Pattern
```python
import numpy as np

# Time vector
t = np.arange(int(FS * DURATION)) / FS

# Sum of sinusoids
signal = np.zeros_like(t)
for freq in FREQUENCIES:
    signal += np.sin(2 * np.pi * freq * t)

# Add noise (typically Gaussian)
# CRITICAL: Choose noise scale carefully. After RMS normalization, the noise
# component gets scaled proportionally. Tests expect residual_std in a specific
# range after fitting and subtracting the tones.
#
# General formula to compute noise_scale:
#   residual_std ≈ noise_scale × (target_rms / signal_rms_before_norm)
#
# For N unit-amplitude sines at well-separated frequencies:
#   signal_rms ≈ sqrt(N × 0.5) = sqrt(N/2)
#
# Therefore:
#   noise_scale = desired_residual_std × signal_rms / target_rms
#
# Worked example for v01 (N=4, target_rms=0.15, desired_residual_std=0.01):
#   signal_rms ≈ sqrt(4/2) = sqrt(2) ≈ 1.414
#   noise_scale = 0.01 × 1.414 / 0.15 = 0.094 ≈ 0.1
#
# For non-unit amplitudes, use: signal_rms = sqrt(sum(amp_i² / 2))
# For target range [a, b], use geometric mean: desired_residual_std = sqrt(a*b)
#
# Always verify empirically after computing noise_scale.

import math
N = len(FREQUENCIES)
signal_rms_approx = math.sqrt(N / 2)  # for unit-amplitude sines
desired_residual_std = 0.01           # target middle of test range [0.004, 0.02]
NOISE_SCALE = desired_residual_std * signal_rms_approx / RMS_TARGET

noise = np.random.randn(len(t)) * NOISE_SCALE
signal += noise
```

### RMS Normalization
```python
def rms_normalize(signal, target_rms):
    """RMS-normalize signal to target_rms."""
    current_rms = np.sqrt(np.mean(signal ** 2))
    if current_rms == 0:
        return signal
    return signal * (target_rms / current_rms)
```

**Key insight**: RMS normalization must happen before 16-bit quantization. The
normalized signal (float in ~[-1,1] range) is directly scaled by 32767 for int16
storage. Do NOT peak-normalize after RMS normalization, as this changes the RMS.

### WAV Export (16-bit PCM)
```python
import wave

def save_wav(filepath, signal, fs):
    # Scale RMS-normalized float signal to int16 range
    int_data = np.clip(signal * 32767, -32768, 32767).astype(np.int16)
    
    with wave.open(filepath, 'w') as wf:
        wf.setnchannels(1)        # Mono
        wf.setsampwidth(2)        # 16-bit = 2 bytes
        wf.setframerate(fs)
        wf.writeframes(int_data.tobytes())
```

## Stage 2: STFT Computation

### scipy.signal.stft API
```python
import scipy.signal as sps

# Standard STFT parameters
stft_params = dict(
    fs=SAMPLE_RATE,
    window='hann',           # or 'blackman', 'hamming', etc.
    nperseg=SEGMENT_LENGTH,
    noverlap=OVERLAP,
    nfft=FFT_SIZE,
    boundary=None,           # or 'zeros', 'even', etc.
    padded=False,            # True to pad signal to fit segments
    return_onesided=True,    # True for real signals
)

f, t, Zxx = sps.stft(signal, **stft_params)
magnitude = np.abs(Zxx)      # Linear magnitude (not dB)
```

### Parameter Relationships
- **Frequency resolution**: `fs / nfft` Hz per bin
- **Number of bins** (one-sided): `nfft // 2 + 1`
- **Time resolution**: `(nperseg - noverlap) / fs` seconds per frame
- **Number of frames**: Computed from signal length and STFT parameters

**Frame count formulas** (compute BEFORE running pipeline to verify output):

For `boundary=None, padded=False`:
```python
step = nperseg - noverlap
n_frames = 1 + (n_samples - nperseg) // step
# Constraint: n_samples >= nperseg (otherwise 0 frames)
```

For `boundary='zeros'`:
```python
# Signal is extended by nperseg//2 zeros on each side
step = nperseg - noverlap
effective_length = n_samples + 2 * (nperseg // 2)
n_frames = 1 + (effective_length - nperseg) // step
# For even nperseg: n_frames = 1 + n_samples // step
```

For `padded=True` (with `boundary=None`):
```python
step = nperseg - noverlap
n_frames = math.ceil(max(n_samples - nperseg + 1, 1) / step)
# Last segment is zero-padded if it doesn't fit
```

**Worked example (v01)**: `n_samples=30000, nperseg=768, noverlap=576`
- `step = 768 - 576 = 192`
- `n_frames = 1 + (30000 - 768) // 192 = 1 + 29232 // 192 = 1 + 152 = 153` ✓

### Magnitude CSV Export

**CRITICAL**: Compute STFT on the **quantized (read-back) signal**, not the original float signal.
Tests read the WAV file back (int16→float), compute STFT on that quantized signal, and compare
values to mag.csv with tight tolerance (rel_tol=1e-6). Computing STFT on the pre-quantization
float signal introduces ~1e-4 relative errors that fail the test.

```python
def compute_and_export_stft(filepath_wav, filepath_mag, stft_params):
    """Read WAV, compute STFT on quantized signal, export magnitude CSV."""
    import wave
    
    # Read back the quantized signal from WAV
    with wave.open(filepath_wav, 'r') as wf:
        frames = wf.readframes(wf.getnframes())
        signal_quant = np.frombuffer(frames, dtype=np.int16).astype(np.float64) / 32767.0
    
    # Compute STFT on the QUANTIZED signal (not the original float)
    f, t, Zxx = sps.stft(signal_quant, **stft_params)
    magnitude = np.abs(Zxx)  # Linear magnitude (not dB)
    
    # Export to CSV
    n_frames = magnitude.shape[1]
    n_bins = magnitude.shape[0]
    
    with open(filepath_mag, 'w') as fout:
        fout.write("frame,bin,val\n")
        for frame_idx in range(n_frames):
            for bin_idx in range(n_bins):
                val = magnitude[bin_idx, frame_idx]
                fout.write(f"{frame_idx},{bin_idx},{val:.10g}\n")
```

**Alternative approach**: Quantize the signal in memory, convert back to float, then compute STFT:
```python
# After RMS normalization
int_data = np.clip(signal * 32767, -32768, 32767).astype(np.int16)
signal_quant = int_data.astype(np.float64) / 32767.0

# Compute STFT on quantized signal
f, t, Zxx = sps.stft(signal_quant, **stft_params)
magnitude = np.abs(Zxx)
```

**Note**: Magnitude array shape is `(n_bins, n_frames)`. Export in linear scale
(not dB) unless task specifies otherwise.

## Stage 3: Peak Extraction with Awk

### Top-k Selection Pattern
```awk
awk -F',' '
BEGIN {
    OFS=","
    # Print header
    print "frame,f1_bin,f2_bin,f3_bin"
}
NR == 1 { next }  # Skip input header
{
    frame = $1
    bin = $2
    val = $3 + 0  # Force numeric conversion
    
    # Maintain top-3 in descending order
    if (!(frame in f1_val) || val > f1_val[frame]) {
        # New maximum: shift down
        f3_val[frame] = f2_val[frame]; f3_bin[frame] = f2_bin[frame]
        f2_val[frame] = f1_val[frame]; f2_bin[frame] = f1_bin[frame]
        f1_val[frame] = val; f1_bin[frame] = bin
    } else if (!(frame in f2_val) || val > f2_val[frame]) {
        # New second: shift third
        f3_val[frame] = f2_val[frame]; f3_bin[frame] = f2_bin[frame]
        f2_val[frame] = val; f2_bin[frame] = bin
    } else if (!(frame in f3_val) || val > f3_val[frame]) {
        # New third
        f3_val[frame] = val; f3_bin[frame] = bin
    }
    
    # Track frame order for output
    if (!(frame in seen)) {
        seen[frame] = 1
        frame_order[++nframes] = frame
    }
}
END {
    for (i = 1; i <= nframes; i++) {
        f = frame_order[i]
        print f, f1_bin[f], f2_bin[f], f3_bin[f]
    }
}
' mag.csv > peaks.csv
```

### Key Awk Patterns
1. **Numeric conversion**: `val = $3 + 0` ensures numeric comparison
2. **Associative arrays**: Use `frame in f1_val` to check existence
3. **Frame ordering**: Track insertion order with `frame_order[]` array
4. **Top-k maintenance**: Cascading if-else to maintain sorted order

### Generalization to Top-k
For arbitrary k, use this complete pattern with parameterized K:

```awk
awk -F',' -v K=3 '
BEGIN { OFS="," }
NR == 1 { next }
{
    frame = $1; bin = $2; val = $3 + 0
    
    # Initialize on first encounter
    if (!(frame in seen)) {
        seen[frame] = 1
        frame_order[++nframes] = frame
        for (i = 1; i <= K; i++) {
            top_val[frame, i] = -1
            top_bin[frame, i] = -1
        }
    }
    
    # Insert into sorted top-K (descending)
    # Use >= instead of > if variant requires "higher bin wins on tie"
    for (i = 1; i <= K; i++) {
        if (val > top_val[frame, i]) {
            for (j = K; j > i; j--) {
                top_val[frame, j] = top_val[frame, j-1]
                top_bin[frame, j] = top_bin[frame, j-1]
            }
            top_val[frame, i] = val
            top_bin[frame, i] = bin
            break
        }
    }
}
END {
    # Build header dynamically
    hdr = "frame"
    for (k = 1; k <= K; k++) hdr = hdr ",f" k "_bin"
    print hdr
    
    for (i = 1; i <= nframes; i++) {
        f = frame_order[i]
        line = f
        for (k = 1; k <= K; k++) line = line "," top_bin[f, k]
        print line
    }
}' mag.csv > peaks.csv
```

**Key design choices**:
- **`-v K=3`**: Parameterize K from command line for variant flexibility
- **`-1` sentinel**: Works for linear magnitude (always ≥ 0). For dB scale (can be negative), use `-1e30` or similar
- **Strict `>`**: Lower bin index wins ties (first encountered in CSV order). Change to `>=` for higher-bin-wins
- **Dynamic header**: Scales with K automatically
- **Frame ordering**: `frame_order[]` array preserves input order for output

**Tie-breaking semantics**: The hardcoded k=3 version uses `val > f1_val[frame]` (strict greater-than). When two bins have exactly equal magnitude, the one encountered FIRST in the CSV wins (lower bin index, since mag.csv iterates bins 0,1,2,...). If a variant requires "higher bin wins on tie", change `>` to `>=`.

## Bash Pipeline Orchestration

### PEAKS_ONLY Mode
```bash
#!/usr/bin/env bash
set -euo pipefail

DATA_DIR="/app/data"
MAG_CSV="${DATA_DIR}/mag.csv"
PEAKS_CSV="${DATA_DIR}/peaks.csv"

if [ "${PEAKS_ONLY:-0}" = "1" ]; then
    # Validate input exists
    if [ ! -f "$MAG_CSV" ]; then
        echo "ERROR: $MAG_CSV not found" >&2
        exit 1
    fi
    
    # Run only peak extraction
    awk -F',' '...' "$MAG_CSV" > "$PEAKS_CSV"
    exit 0
fi

# Full pipeline
python3 /app/audioproc.py
awk -F',' '...' "$MAG_CSV" > "$PEAKS_CSV"
```

**Critical**: Use `PEAKS_ONLY=1 bash script.sh` to invoke PEAKS_ONLY mode. The
script must check `${PEAKS_ONLY:-0}` to handle unset variable.

## Variant Configuration

### Synthesis Parameters (vary per spec)
- `FS`: Sample rate (e.g., 12000, 16000, 44100 Hz)
- `DURATION`: Signal length in seconds
- `FREQUENCIES`: List of tone frequencies in Hz
- `NOISE_SCALE`: Standard deviation of Gaussian noise
- `RMS_TARGET`: Target RMS after normalization

### STFT Parameters (vary per spec)
- `window`: Window function ('hann', 'blackman', 'hamming', etc.)
- `nperseg`: Samples per segment
- `noverlap`: Overlap between segments
- `nfft`: FFT size (zero-padded if > nperseg)
- `boundary`: Boundary handling (None, 'zeros', 'even', etc.)
- `padded`: Whether to pad signal to fit complete segments
- `return_onesided`: True for real signals, False for complex

### Peak Extraction Parameters (vary per spec)
- `K`: Number of top peaks to extract
- Output schema: column names and ordering
- Tie-breaking rules (if specified)
- Frame grouping logic (if different from per-frame)

## Verification Checklist

### WAV File
- [ ] Correct sample rate, duration, channels, bit depth
- [ ] RMS within tolerance (e.g., 0.15 ± 0.002)
- [ ] Mono, 16-bit PCM format

### Magnitude CSV
- [ ] Header: `frame,bin,val`
- [ ] Linear magnitude (not dB)
- [ ] Correct number of bins: `nfft // 2 + 1` (one-sided)
- [ ] Correct number of frames based on STFT parameters
- [ ] Total rows: `1 + n_bins * n_frames`

### Peaks CSV
- [ ] Header: `frame,f1_bin,f2_bin,f3_bin` (or variant schema)
- [ ] One row per frame
- [ ] Bins in descending magnitude order: `f1 >= f2 >= f3`
- [ ] 0-indexed bin numbers
- [ ] Generated by awk, not Python

### Pipeline
- [ ] `PEAKS_ONLY=1` mode works correctly
- [ ] Full pipeline produces all three outputs
- [ ] Directory structure matches specification

## Common Pitfalls

1. **Double normalization**: Don't peak-normalize after RMS normalization
2. **STFT on wrong signal**: Compute STFT on the QUANTIZED (read-back) signal, not the original float. Tests compare mag.csv against STFT of the WAV file contents. Pre-quantization float introduces ~1e-4 relative errors that fail tight tolerances (1e-6).
3. **Noise scale too small**: Use the general formula to compute noise_scale from desired residual_std. For N unit-amplitude sines: `noise_scale = desired_residual_std × sqrt(N/2) / target_rms`. Too-small noise_scale (e.g., 0.01 for v01) produces residual_std below test minimum. Always verify empirically after computing.
4. **Magnitude scale**: Export linear magnitude unless dB is explicitly required
5. **Array indexing**: scipy STFT returns `(n_bins, n_frames)`, not `(n_frames, n_bins)`
6. **Awk numeric comparison**: Always force numeric with `+ 0`
7. **Frame ordering**: Awk processes rows sequentially; track frame order explicitly
8. **PEAKS_ONLY validation**: Check that mag.csv exists before processing
9. **File paths**: Use absolute paths in scripts for reliability
