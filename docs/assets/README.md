# Figures and presentation assets

| Asset | Source |
| --- | --- |
| `ssl-banner.svg` | Editable SSL wordmark and project banner; embeds the NJU-LINK lab logo from the laboratory's preprint template. |
| `ssl-banner.png` | Project banner rendering. |
| `nju-link-logo.svg`, `.png` | Official NJU-LINK logo extracted from the laboratory artwork embedded in `ssl-banner.svg`; a white backdrop preserves contrast in dark mode. The README uses the PNG rendering. |
| `method-overview.png` | High-resolution rendering of the method overview in the current SSL paper, without changes to the figure's content. |
| `learning-example.svg`, `.png` | Static view of the released Fixed-Window SSL financial-report example; exact evidence is linked in [the annotated run](../learning-example.md). |
| `results-overview.svg`, `.png` | Main utility comparison and Educator-token comparison. Utility comes from the offline summary of released records; token reduction comes from the current paper. |
| `results-data.json` | Main-comparison values used in the results graphic, plus shared-subset scores and Educator-token savings used in the README. |
| `evaluation-scale.svg` | Compact main-evaluation summary: 22 families, 155 held-out cases, and 3 independent runs, consistent with `results-data.json`. |

The SVG sources are retained for editing and export. PNG renderings are
available for viewing and reuse. The README displays the lab logo and method
overview; evaluation-scale, full-results, and case graphics remain available
as separate assets. The embedded lab logo preserves the original artwork.
